# Rules for AI assistants working on Gearantee

## Feature tracking (required)

When you finish, start, or submit a PR for a WBS feature:

1. Open `doc/PROJECT_MILESTONES.md`.
2. Follow its **How to update this file** section exactly: update the feature row (Status, Actual Start/End, PR), tick milestone checkboxes only when all of their WBS rows are Done, recalculate the Progress summary, and add a Change log line.
3. Include that file in the same commit/PR as the feature.
4. Do not change baseline dates, owners, or other members' rows unless the user explicitly asks.

If the work is not in the WBS, add it to **Additional work (not in WBS)**.
